## Homework 2 Report

### Abstract
Основной идеей было построить гибридный рекоммендер, который объединяет кандидатов от двух независимых моделей (SASRec и LightFM) с помощью алгоритма Reciprocal Rank Fusion, а затем переранжирует их, опираясь на семантическую близость к якорному треку текущей сессии.
Якорь выбирается из истории прослушиваний пользователя (взвешенный рандом по времени прослушивания). По идентификатору якоря запрашиваются кандидаты из двух Redis-хранилищ — отдельно от SASRec и от LightFM. Ранги кандидатов из двух источников объединяются по формуле RRF.
Для разнообразия рекомендаций применяется штраф за повторяющихся авторов.

Финальный порядок треков определяется формулой:
Score = 0.65 * semantic_score + 0.35 * rrf_rank_score - 0.05 * количество треков автора в истории

#### Оффлайн: Создание эмбеддингов треков
1. Из tracks.json берем метаданные: title, artist, genres, mood, summary.
2. С помощью TfidfVectorizer преобразуем объединенный текст в разреженную матрицу
3. С помощью TruncatedSVD сжимаем полученную матрицу до размерности 128
4. Нормализуем векторы (по L2), чтобы скалярное произведение равнялось косинусному сходству.
5. Сохраняем словарь {track_id:эмбеддинг трека} в data/embeddings.joblib

#### Онлайн: Ранкинг гибридных рекомендаций
1. Для каждого автора из истории прослушиваний считаем сколько его треков в истории
2. Выбор Якоря: Алгоритм выбирает один трек из истории (взвешенный рандом).
3. Загрузка кандидатов из двух источников: по ключу anchor_id запрашиваем списки кандидатов из Redis
4. Reciprocal Rank Fusion (RRF): для каждого уникального трека считаем
   rrf_score = 1 / (k + rank_sasrec) + 1 / (k + rank_lightfm),  k = 60
   и сортируем кандидатов по убыванию rrf_score
5. Фильтрация: убираем из списка уже прослушанные треки.
6. Финальный скоринг: для каждого кандидата считаем
   score = 0.65 * dot(anchor_vec, cand_vec) + 0.35 * (1 - i / (N - 1)) - 0.05 * artist_count_in_history
   и выбираем трек с максимальным значением.

Размер истории пользователя - 20 треков, в качестве fallback_recommender используется random_recommender(возвращает случайный трек).
